## 3. 真机实测发现并当场修复的缺陷

| 缺陷编号 | 严重度 | 问题描述 | 修复方案与复测结果 |
| :--- | :---: | :--- | :--- |
| `DEF-10` | P1 | `SonifyCrashHandler` 拉起独立 `:crash` 进程时未透传 `activeBaseUrl`，导致用户在自定义/镜像服务地址下无法将崩溃日志自动上报至所选服务 | 在 `SonifyCrashHandler` 与 `CrashRecoveryActivity` 间增加 `EXTRA_BASE_URL` 透传并在自动/手动上报链路统一使用；复测 `:crash` 页当场显示「脱敏日志已上报」且服务端 `.jsonl` 实时落盘 |
| `DEF-11` | P2 | `server/sonify_server.py` 的 `--releases-dir` 参数默认写死 `/var/lib/sonify-server/releases`，未随自定义 `--data-dir` 推导，导致非 root 本地目录运行报错 | 改为 `--releases-dir` 默认 `None`，未显式指定时自动推导为 `<data-dir>/releases`；本地实测启动与 Range 下载 100% 通过 |
