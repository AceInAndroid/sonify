## 3. 真机验收中发现并即时修复的缺陷

| 缺陷 ID | 现象与根因 | 修复方案与回归结果 |
|---|---|---|
| **DEF-16** | 初版 `ProvideAppLanguage` 直接以 `ConfigurationContext` 覆盖 `LocalContext`，导致 `rememberLauncherForActivityResult` 找不到宿主 `ActivityResultRegistryOwner`。 | 改为 `ContextWrapper(baseContext)` 仅覆写 `resources` / `assets` 并显式透传 `LocalActivityResultRegistryOwner` 与 `LocalOnBackPressedDispatcherOwner`，新增 `Context.findActivity()` 辅助函数；真机启动零崩溃。 |
| **DEF-17** | 热切换至 English 后，Material3 `AlertDialog`（如 Release Changelog）内部独立子窗口读取了尚未刷新的宿主 Activity `Resources`，标题仍短暂显示中文。 | `ProvideAppLanguage` 切换语言时同步就地更新宿主 Activity 与 Application `Resources` 配置；复测热切换后立即打开 `Release Changelog` 弹窗 100% 英文呈现。 |
| **DEF-18** | 英文版 Local Library 顶部排序芯片（`Recently Added ↓ · 77`）较长，将右侧 `Shuffle` 按钮挤成两行 `Shu / ffle`；且 `HiFiApp.localizedContext()` 缓存未按语言键失效导致 `Continue Listening` 残留中文。 | 排序芯片增加 `weight(1f, fill = false)` + `TextOverflow.Ellipsis`，操作芯片设置 `maxLines = 1, softWrap = false`；`HiFiApp.localizedContext()` 按持久化语言键按需刷新。真机复测两项全部恢复单行齐整与全英文显示。 |
