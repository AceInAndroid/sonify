## 3. 实测中发现并即时修复的缺陷

| 缺陷 ID | 现象与根因 | 修复方案与回归结果 |
|---|---|---|
| **DEF-13** | 下载刚启动 `downloadedBytes == 0L` 时进度栏误显示 `0% · 未知大小 / 26.9 MB`（复用 `formatSize(0L)` 返回「未知大小」）。 | 新增 `UpdatePolicy.formatProgressBytes()`，0 字节返回 `"0 KB"` 并补齐单测；真机回归显示正常。 |
| **DEF-14** | 通过 Cloudflare 代理 → Caddy 2 → Python `BaseHTTPRequestHandler`（默认 `HTTP/1.0`）流式下载 APK 时，长连接触发 HTTP/2 `INTERNAL_ERROR` / Caddy `i/o timeout` 中断。 | 服务端升级 `protocol_version = "HTTP/1.1"`、显式输出 `Connection: close` + `Cache-Control: no-store`、读取 `CF-Connecting-IP` 并静默处理 `BrokenPipeError`；客户端 `AppUpdateManager` 独立配置 `Protocol.HTTP_1_1` 下载专用 `OkHttpClient`。部署并真机回归 `https://sonify.zhangbing.tech` 下载与 SHA-256 校验一次通过。 |
