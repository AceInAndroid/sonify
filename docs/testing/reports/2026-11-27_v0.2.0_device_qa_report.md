## 2. 真机实测捕获并闭环修复的缺陷清单

本次真机实测与逐帧截图审查共发现 **8 个真实缺陷**（其中 **1 个 P0、2 个 P1** 均为单元测试无法暴露的真机运行时/视觉问题），全部当场修复并重新编译安装到 `3917JR` 回归通过：

| 编号 | 级别 | 所属模块 | 现象与根因 | 修复方案与回归结果 |
| :---: | :---: | :---: | :--- | :--- |
| **DEF-01** | **P0** | 音乐库歌单 | 点击本地自建歌单后，歌单详情页无法打开并直接退回歌曲列表。根因：`MainActivity.kt` 中 `observeLocalPlaylist(id).collectAsState(initial = null)` 首帧先发射 `null`，立即触发 `else { LaunchedEffect(Unit) { openLocalPlaylistId = null } }` 将刚打开的歌单强制关闭。 | 以内存中已加载的 `localPlaylists` 对应项作为 `initial` 与回落值（`MainActivity.kt`）。回归验证：点击歌单秒开详情页并稳定停留，支持 2×2 封面、随机播放、批量管理、编辑与删除。**已关闭** |
| **DEF-02** | **P1** | 沉浸歌词 | 歌词播放期间自动滚屏不断误触发「回到当前句」胶囊，且 5 秒自动隐身纯享态永远无法生效。根因：`LyricsView.kt` 监听 `listState.isScrollInProgress`，而程序调用 `animateScrollToItem()` 同样会置位该状态。 | 改为监听 `listState.interactionSource.collectIsDraggedAsState()` 仅响应真实手指拖拽（`LyricsView.kt`）。回归验证：正常播放不再误弹「回到当前句」，静置 5 秒自动淡出顶/底栏进入极净纯享歌词态，轻点即刻唤醒。**已关闭** |
| **DEF-03** | **P1** | 音乐库多选 | 播放歌曲存在悬浮 MiniPlayer 时，多选模式底部的「加入歌单」金色按钮被 MiniPlayer 遮挡一半。根因：`MainActivity.kt` 计算 `bottomClearance` 时未叠加底部系统导航栏 `WindowInsets.navigationBars` 高度。 | `bottomClearance` 改为 `navBarBottomDp + if (hasMiniPlayer) 140.dp else 68.dp`（`MainActivity.kt`）。回归验证：多选操作栏完整悬浮于 MiniPlayer 上方，零遮挡。**已关闭** |
| **DEF-04** | **P2** | WiFi 传歌 | 在 1080p 屏幕上局域网地址框截断为 `http://192.168.31.23...`，用户无法肉眼读全端口号。 | 调优字号至 `13.sp`、收紧图标内边距并禁用折行（`WifiTransferSheet.kt`）。回归验证：完整清晰显示 `http://192.168.31.233:8088`。**已关闭** |
| **DEF-05** | **P2** | 沉浸歌词 | 歌词页底部工具栏右下角时间在 360dp 屏宽下折成两行（`00:27 /` 换行 `04:40`）。 | 精简按钮文案为「搜词」、收紧胶囊间距并为时间文本设置 `maxLines = 1, softWrap = false`（`LyricsView.kt`）。回归验证：单行锐利对齐。**已关闭** |
| **DEF-06** | **P2** | 沉浸歌词 | 半屏实时样式面板透明度偏高（`0xE8`），底层歌词和播放键略微透出影响观感；副标题末字「效」孤行换行。 | 提升面板不透明度至 `0xF7141417` 增强可读性，精简副标题为单行「调节参数，上方歌词实时生效」（`LyricsStyleSheet.kt`）。回归验证：面板通透干练、上方实时预览无干扰。**已关闭** |
| **DEF-07** | **P2** | Subsonic | 中文输入法未切英文时在服务器地址框误敲全角标点（`：` / `／` / `。`）会导致 URL 解析失败。 | 在 `SubsonicAuth.normalizeBaseUrl()` 中自动规范化全角标点与协议大小写，并补充单元测试（`SubsonicAuthTest.kt`）。回归验证：单测与真机登录均通过。**已关闭** |
| **DEF-08** | **P2** | 远程歌单 | 远程歌单详情页操作栏同时展示「加歌 / 默认顺序 / 已离线 / 随机 / 播放」时，最右侧 46dp 圆形播放键被挤压成窄椭圆。 | 将左侧功能胶囊包裹为 `Modifier.weight(1f).horizontalScroll(...)`，锁定右侧随机与 46dp 圆形播放键尺寸（`PlaylistDetailScreen.kt`）。回归验证：编译与真机布局通过。**已关闭** |
| **DEF-09** | **P0** | 收藏同步 | 点击播放页或曲目菜单的「收藏」按钮触发闪退：`IllegalStateException: Player is accessed on the wrong thread`。根因：`PlayerViewModel.toggleFavorite()` 在 `Dispatchers.IO` 协程直接调用 `HiFiPlaybackService.notifyFavoriteChanged()` 读取 `player.currentMediaItem`。 | 1. `PlayerViewModel.toggleFavorite()` 改为仅数据库/远程请求走 `withContext(Dispatchers.IO)`，UI 状态与 `notifyFavoriteChanged()` 留在主线程执行；<br>2. `HiFiPlaybackService.notifyFavoriteChanged()` 内部强制 `serviceScope.launch(Dispatchers.Main.immediate)` 双层兜底。真机复测 `TC-REG-05`：播放页心形键与曲目菜单往返收藏/取消收藏进程 PID 稳定、视觉变绿正常、`logcat` 零崩溃。**已关闭** |
